# Fundamentum

Source code of [Fundamentum](https://www.curseforge.com/minecraft/mc-mods/fundamentum), the shared groundwork under
Oculifelis's mods: raised health cap, data tables, mounts, grappling hooks, summons, whips, moons, sieges, elemental
damage and portal crafting, all driven by datapack JSON.

Each Minecraft version is its own Gradle project (`neoforge-26.1.2`, `neoforge-26.2`, `neoforge-26.3`,
`neoforge-1.21.1`, `forge-1.20.1`). Build one with `./gradlew build` inside its folder.
